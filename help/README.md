# 720VIP環景平台與大學院校合作

## 共創產學雙贏
1. 教學課程：結合課程教學讓學生實作空間導覽系統
2. 專題輔導：專題輔導學生實作空間導覽系統
3. 平台支援：學生在校免費有限制使用，畢業後商業付費使用
4. 產學合作：授權學校使用即可開放更多空間

## 市場定位：校園互動式環景導覽平台
1. 校園空間導覽：招生、校園介紹、行政單位、教室及特色場域。
2. 系所設備介紹：將環景與設備照片、介紹影片及系所網站連結整合。
3. 學生實作課程：學生拍攝環景、建立導覽、設計互動內容並發表作品。
4. 數位典藏與成果展示：校園歷史、圖書館、展覽空間、特色教學成果。

## 推廣方式：業師協同教學講座(針對老師)
1. 環景導覽系統與產業應用(5分鐘)
2. 環景平台案例及功能展示(10分鐘)
3. 課程說明及專題實作方式(10分鐘)
4. 合作方式及教學心得交流(15分鐘)

## 課程方案一：三小時課程(大三專題學生)
1. 認識環景與導覽系統與業界應用(20分鐘)
2. 選定拍攝主題與環景相機拍攝技巧(30分鐘)
3. 現場環景拍攝與相關素材收集(20分鐘)
4. 環景平台註冊與操作使用教學(30分鐘)
5. 多媒體連結與環景轉影片教學(20分鐘)
6. 完成作品發表與其他建議(30分鐘)

## 課程方案二：6週微課程(專業選修)
1. 認識環景與導覽系統與業界應用(2-3小時)
2. 學生分組討論與環景相機拍攝技巧(2-3小時)
3. 現場環景拍攝與相關素材收集(2-3小時)
4. 環景平台註冊與操作使用教學(2-3小時)
5. 多媒體連結與環景轉影片教學(2-3小時)
6. 完成作品發表與其他建議(2-3小時)

## 課程方案三：18週課程(專業選修)
1. 認識環景與導覽系統與概念說明(第1週)
2. 業界應用與環景導覽系統案例分享(第2週)
3. 學生分組分工討論與選定拍攝地點(第3週)
4. 環景相機拍攝技巧及注意事項(第4週)
5. 小組環景照片與平面照片拍攝(第5週)
6. 小組人工格局圖繪製與相關素材收集(第6週)
7. 環景平台註冊與操作使用教學(第7週)
8. 透過AI生成格局圖並加入導覽系統(第8週)
9. 導覽系統書面規劃報告(第9週)
10. 環景、圖片、網址等多媒體連結(第10週)
11. 空間導覽文字或圖片說明立牌製作(第11週)
12. 主題空間文案介紹與語音檔製作(第12週)
13. 環景轉影片含文字轉語音教學(第13週)
14. 透過AI生成符合環景情境的影片(第14週)
15. 導覽網址分享及崁入網頁實作(第15週)
16. 期末成果簡報準備(第16週)
17. 完成作品發表與其他建議(第17週)
18. 作品檢討與補救措施(第18週)

## 720VIP環景平台教育方案
1. 學生免費使用：每1個帳號有免費建立1個導覽空間，上限為10個環景
2. 購買教育授權：帳號以班級數為單位、授權期間以學期為單位
3. 專題輔導課程：配合專題製作課程，三小時專題輔導課程
4. 協同教學課程：配合已開18週課程以業師協同教學6週課程
5. 教授學期課程：兼任講師授課18週課程
